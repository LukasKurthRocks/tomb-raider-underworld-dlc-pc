# One entry per line: path | label | item id [argument]
#   path     the ring level: "Cheats", "Objekte/Kisten" ("/" = a level below); a level with more than 8 entries gets
#            pages (LB / RB). Levels show up in the order of their first line.
#   label    the text in the sector - ASCII only (the menu font has no umlauts), at most 47 characters
#   item id  a TruMenu item as typed into the command bar ("list" there shows all); a bool item without an argument
#            switches to the other state and shows on / off in its sector
# Never offered (dropped with a log line): game.quit, cmd.run, save.delete, save.restore, save.import, settings.reset.
# Unknown ids are greyed out and named in TruMenu.log. "menu radial.reload" (or the item in the command bar) reads the
# file again; tools/trumenu_ini_check.py checks the shipped file.
