# TruMenu switches (TruMenu 0.21.5) - Set-TruMenu.ps1 copies it next to tru.exe as TruMenu.switches.txt.
# The plugin INI switches of the quick bar page "Fixes" and the long menu section "Fixes" (one source for both).
# A row edits <Plugin>.ini next to the .asi files (WritePrivateProfileString, the TO TEST toggle path); the INI must
# exist (a plugin that is not installed is shown "keine INI" and never written), TruMenu never creates a plugin INI.
#
# Group line:  group | <key> | <DE heading> | <EN heading> [| open]
#   key        letters / digits / _ (at most 23); "open" = the group starts open. One group is open at a time.
# Switch line: <Plugin> | <Section> | <Key> | <type> | <DE text> | <EN text> | <when> | <default> | <hint> [| <since>]
#   Plugin     Tru + letters / digits (its INI = <Plugin>.ini next to tru.exe); Section / Key letters / digits / _
#   type       bool (0 / 1) | int:<lo>..<hi>[:<step>] | choice:<a>,<b>,... (exact INI values)
#   when       live = the plugin re-reads the key while the game runs (about once a second);
#              restart = read once at the game start (takes effect at the next start);
#              live-if:<Key> = live only while <Key> of the same section is 1 at the start, else restart
#   default    the value of the shipped plugin INI (the plugin's default)
#   hint       one short line (footer / tooltip), ASCII
#   since      optional "<Plugin> <version>": the row belongs to that plugin version (key / default may be missing or
#              differ in the installed INI until it is installed)
# ASCII only (the menu font has no umlauts), at most 160 switch lines and 24 groups. Text values (PathFilter,
# SpawnFilter, ProgressFilter) are no switches and are not listed. tools/trumenu_ini_check.py checks every key against
# the shipped plugin INIs and every "live" claim against the plugin's re-read function.
