# Upstream workspace `work/ws/` - map (2026-10-27)

Upstream's `work/ws/` holds the author's working scripts (40 folders, 578 Python files). They read intermediate
builds from `work/baseline/B<n>/mods` and overlay layers from `work/mods_fix<n>/` etc.; **neither is in the repository**
(they contain converted game data). This page maps folders to builds and layers so that stage 2b of the rebuild
(`docs/WINDOWS_REBUILD.md`) can find the script behind each fix.

Sources: `docs/LINEAGE.md` (what each build added), `docs/data/B90_gold_L4.manifest.tsv` (origin of every file),
`work/ws/rebuild/build_effective.py` (`ORDER`, install order), `work/ws/rebuild/compare_rebuild.py` (`CHRONO`,
chronological order with the fixes wired into the pipeline). Table generated by `tools/ws_map.py`.

## Two numbering systems

- **Builds `B<n>`** (`work/baseline/B<n>/`): numbered snapshots, B1-B90 plus labels (`B86_contratti`,
  `B87_materiali19`, `B88b_acqua`, `B90_gold_L4`); later releases B132, B138. `LINEAGE.md` lists what each added.
- **Overlay layers** (`work/mods_fix12`, `mods_glitchfix`, `mods_next`, `mods_current`, ...): folders installed on top
  of each other in the author's test VM. The B90 manifest's origin column names both (`derived:B43`, `mods_fix12`,
  `vm_mods_expected`, ...).

## The author's own rebuild check (`work/ws/rebuild/`)

- `convert_fresh.py`: reconverts every pack10 DRM with the current pipeline (`assemble_dlc.assemble`, silent waves,
  `pc_copy`, `template`, `material='dlc'`) into `out_fresh/`.
- `build_effective.py`: the effective installed overlay (`installed_effective.tsv`).
- `compare_rebuild.py`: section- and word-level comparison fresh vs installed; every differing word is attributed
  to the layer that introduced it (`EXPLAINED:<layer>`, `HOOK_NOT_FIRING`, `DRIFT`, `RESID`).
- `ablate.py`: reconverts with one wired fix switched off.

This is the same idea as our stage comparison; it needs the layer folders, which are not public. With only the B90
manifest and the installed B138 tree, our attribution has to go by file origin (manifest) and section type.
